# Changelog

All notable changes to this project will be documented in this file.

## [1.1.0] - 2026-05-08

### Added
- **Advanced Hooks**: `useLocalStorage`, `useWindowSize`, `useTheme`, `useChat`, and `useAuth`.
- **Premium Components**: `Badge`, `Modal` (Portals), `Tooltip`, `Toast`, and `TypingIndicator`.
- **Interactivity**: Staggered cinematic animations for the Welcome Screen and checkmark pop effects.
- **Architecture**: Professionalized Mermaid diagram with grouped layers and improved iconography.
- **DevOps**: `Dockerfile` and `.dockerignore` for containerization.
- **Templates**: GitHub Issue and Pull Request templates.
- **Security**: Official `SECURITY.md` policy.

### Changed
- Refactored Auth views (`Login`/`Register`) to use the standardized `Button` component.
- Enhanced global avatar styles with hover zoom effects.
- Optimized README with a detailed Data Flow & Interaction guide.

## [1.0.0] - 2026-05-08

### Added
- Standardized UI component system (Button, LoadingSpinner, EmptyState).
- Global Error Boundary for application stability.
- Professional documentation (CONTRIBUTING, CODE_OF_CONDUCT, README updates).
- SEO meta tags and social sharing metadata.
- Custom modern scrollbars and global transition effects.
- Path aliases for cleaner development imports.
- VS Code workspace configuration.
- MIT License.

### Changed
- Centralized CSS variable system into a token-based architecture.
- Refined button interaction states and sidebar animations.
- Optimized package metadata and versioning.

### Fixed
- Improved mobile responsiveness for core UI elements.
- Cleaned up unused styles and standardized code formatting.
